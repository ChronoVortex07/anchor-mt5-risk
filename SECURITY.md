# Security reports

Please use this repository's **Security → Report a vulnerability** feature for security-sensitive findings. Do not post usable tokens, account identities, pairing codes or exploit details in public issues. If private reporting is unavailable, open a minimal issue asking for a private reporting channel without disclosing the vulnerability.

The first release is a source prerelease and is not live-trading certified. No support SLA or guaranteed remediation timeline is offered. See [the threat model](docs/threat-model.md) and [remaining risks](docs/remaining-risks.md). Broker execution must be validated on demo accounts before live deployment.
